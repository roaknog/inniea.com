FLOW CHART FOR CREATING A WEB HOSTED SITE.

00. Along with a used office computer(s), get non-residential internet and buy your own router. Those last two items will enable you to use port 80 for web sites.
01. Install Ubuntu Server 23.04. Desktop will not cut the mustard.
02. Install SSH. Youtubers miss this one and it is important. Those youtubers are they, the people who live over there and do that to them. The server should actually be called a LSAMP server not a LAMP server.
03. Install Apache.
04. Install UFW. This is necessary to find errors and manage ports.
05. Install MySQL.
06. Install PHP.
07. Create your domain directory folder called /var/www/"yourdomainname.com".
08. Create your home page called index.html in /var/www/"yourdomainname.com".
09. Create a virtual host file called /etc/apache2/sites-available/"yourdomianname".com.conf.
10. Disable the file /etc/apache2/sites-available/000-default.conf.
11. Your web page is your IP Address until you assign it a purchased domain name.
12. Forward your router ports 20,21 for ftp and 80 for html.
13. If not using server, make your IP Address static by editing /etc/netplan/01-network-manager-all.yaml adding default address. Your internet service provider is not going to give you a free static IP Address.
14. Point the domain name you purchased in your name server host to your IP Address.
15. Install vsftpd so clients can acccess their files remotely.
16. Clients install free FileZilla on their remote computers to access their accounts with host name which is computer IP address, their user name, their password, and port 21.
17. Create email with MySQL and PHP after installing Postfix and Dovecot.
18. . . .
